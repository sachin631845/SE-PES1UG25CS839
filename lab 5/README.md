# Lab 5: Voting and Election System

## Project Overview
This project implements a voting and election management system in Python. It supports voter registration, vote casting, vote counting, turnout calculation, and postal ballot importing.

## Static Analysis Tools
- **Pylint:** Checks Python code quality and coding standards.
- **Bandit:** Identifies potential security issues.
- **Flake8:** Checks code style and common programming errors.

## Code Improvements
- Prevented duplicate voting.
- Added candidate and voting-time validation.
- Replaced MD5 with SHA-256 hashing.
- Used secure random number generation.
- Improved XML parsing security.
- Removed unused code and corrected style issues.
